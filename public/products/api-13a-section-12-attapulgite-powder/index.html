Industry Definition & Specification Standard:

API 13A Powder (certified under American Petroleum Institute Specification 13A Section 12) is an industrial drilling-grade Attapulgite / Palygorskite clay (CAS 12174-11-7, HS Code 25084000). Unlike conventional bentonite which collapses in saline water, API 13A powder forms a mechanical 3D crystalline needle brush-pile matrix that maintains apparent viscosity (≥30–36 cps @ 600 RPM) and high cutting-carrying yield point in saturated salt brines (up to 300,000 ppm TDS of NaCl, KCl, and CaCl₂).

Frequently Asked Questions About API 13A Powder

What is API 13A Powder?

API 13A Powder is high-purity Attapulgite (Palygorskite) clay manufactured strictly in accordance with American Petroleum Institute (API) Specification 13A Section 12. It functions as a specialized drilling mud viscosifier for offshore wells, marine drilling, and saturated brine workovers where ordinary bentonite flocculates and fails.

What are the required laboratory test specifications for API Spec 13A Section 12?

According to API Spec 13A Section 12, the standard requirements tested on a calibrated Fann Model 35 direct-indicating viscometer in saturated saltwater are: 1) Viscometer dial reading at 600 rpm: Minimum 30 cps; 2) Wet screen residue greater than 75 μm (200 mesh): Maximum 8.0%; 3) Moisture content: Maximum 16.0% by weight. Bentoclay consistently surpasses these metrics with 32 to 36 cps viscosity.

What is the difference between API 13A Section 9 (Bentonite) and Section 12 (Attapulgite)?

API 13A Section 9 covers drilling grade sodium bentonite, which swells through electrostatic platelet hydration and functions solely in freshwater muds (collapsing in saltwater). In contrast, API 13A Section 12 covers drilling attapulgite clay, which forms a mechanical three-dimensional crystalline needle network completely immune to dissolved salts, making it the industry standard for marine and saturated brine drilling fluids.
